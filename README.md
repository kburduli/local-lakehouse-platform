# local-lakehouse-platform

Production-oriented local lakehouse platform built with Spark, Iceberg, MinIO (S3-compatible storage), Hive Metastore, and StarRocks.

The project focuses on modern batch data engineering concepts including:
- incremental loading
- medallion architecture (Bronze/Silver/Gold)
- metadata management
- partitioning strategies
- analytical serving patterns
- local lakehouse infrastructure

## Planned Stack

- Apache Spark
- Apache Iceberg
- MinIO
- Hive Metastore
- StarRocks
- Docker Compose
- Python
- SQL

## Project Goals

- Build a production-style local lakehouse environment
- Simulate real-world batch ETL pipelines
- Explore Spark and Iceberg internals
- Implement incremental processing patterns
- Practice data platform architecture and engineering concepts
- Integrate analytical serving with StarRocks
